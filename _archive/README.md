# 项目归档目录

此目录存放项目历史遗留的临时文件、旧脚本和已完成任务的相关文件。

**⚠️ 注意：这些文件仅供参考，不建议重复运行或修改。**

## 📁 目录结构

```
_archive/
├── old_scripts/          # 旧脚本（一次性任务）- 10个文件
├── temp_logs/            # 临时日志文件 - 25个文件
└── migrations/           # 历史迁移脚本 - 9个文件
```

## 📂 分类说明

### old_scripts/
一次性任务脚本，已完成：
- CSSCI 扩展版相关脚本
- 数据清理脚本
- 字段映射修复脚本

### temp_logs/
运行时产生的日志文件：
- 批量更新日志
- 并发更新日志
- 自动运行日志
- 进度文件

### migrations/
数据库迁移脚本（已执行）：
- PostgreSQL 迁移
- 字段添加
- 索引创建

## 🗑️ 清理建议

这些文件可以在项目稳定后考虑删除，或移动到长期存储。

**建议保留时间：** 项目正式上线后6个月
