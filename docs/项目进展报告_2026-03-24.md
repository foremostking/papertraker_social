## 📊 项目概述

PaperTracker Social 是一个帮助学术小白完成核心期刊论文全流程的系统。本项目已完成数据层、API层和前端基础界面开发，实现了**1062本CSSCI期刊**的数据管理与查询功能。

## 🛠 技术栈

### 后端
- **框架**: FastAPI
- **数据库**: PostgreSQL
- **缓存**: Redis
- **ORM**: SQLAlchemy
- **数据验证**: Pydantic

### 前端
- **框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **UI组件**: Ant Design 5
- **图表**: @ant-design/charts
- **路由**: React Router v6
- **数据获取**: @tanstack/react-query
- **HTTP**: Axios

### 开发工具
- **容器**: Docker + docker-compose
- **数据库迁移**: Alembic
- **API文档**: FastAPI自动生成

## 🔗 快速启动

### 后端服务
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
API文档: http://localhost:8000/docs

### 前端服务
```bash
cd web
npm install
npm run dev
```
访问地址:
- 管理界面: http://localhost:5173/admin
- 用户界面: http://localhost:5173/

## 📝 API端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/journals/` | GET | 获取期刊列表（支持筛选、分页） |
| `/api/journals/stats` | GET | 获取统计信息 |
| `/api/journals/fields` | GET | 获取学科列表 |
| `/api/journals/{id}` | GET | 获取期刊详情 |
| `/api/journals/{id}/frameworks` | GET | 获取框架模式 |
| `/api/journals/{id}/analyze` | POST | 触发框架分析 |
