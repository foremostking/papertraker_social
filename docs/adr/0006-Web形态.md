# ADR-006：Web 采用 Streamlit 最小监控面板

- 状态：已接受（已实现）
- 日期：2026-08-05
- 实现日期：2026-08-08
- 关联：ADR-007（P5）

## 背景

仓库中并存 4 种前端形态：`web/`（FastAPI/React 工程化前端）、Streamlit 脚本、CLI 交互、以及未来可能的 MCP 客户端 UI。工程化前端维护成本高，而项目当前处于收敛阶段，核心价值在采集与分析管线，前端只需满足"能看进度、能看结果"即可。

## 决策

**Web 形态收敛为 Streamlit 最小监控面板，废弃工程化前端。**

面板定位为监控面板，含 3 页：

- 项目列表：展示所有项目与状态。
- 项目详情/进度：展示单个项目的采集与处理进度，以及结果查看。
- 设置：展示和配置 API Key 及模型参数。

面板直接复用引擎与检索层的 Python 类，不引入独立 API 网关。

**实现说明（2026-08-08 更新）**：实际实现中保留了三项写操作——创建项目、启动生成、保存 API Key——因为纯只读面板无法满足用户通过浏览器完成完整研究流程的需求。写操作仅涉及项目元数据写入和环境变量配置，不涉及核心管线逻辑变更，风险可控。

## 后果

- **正面**：单语言（纯 Python）、零前端构建链；依赖少（仅 streamlit）；与后端共享数据模型与配置，调试直观。
- **负面/成本**：Streamlit 不适合复杂交互与高并发实时编辑场景——但监控面板无需这些能力。
- **迁移**：原 `web/` 工程化前端已归档进入 ADR-001 归档区（`_archive/`），P5 阶段以 Streamlit 面板替代。
- **实现文件**：`web/app.py`（项目列表+创建+设置）、`web/pages/project_detail.py`（进度+结果）、`web/styles.py`（统一样式系统）、`start_web.bat`（Windows 启动脚本）。依赖声明于 `pyproject.toml` 的 `[project.optional-dependencies] web` 组。

## 不决策的内容

- 不保留 React/FastAPI 工程化前端作为主 UI（避免双前端维护）。
- 不在 Streamlit 面板中实现复杂交互（如拖拽排序、实时协作编辑）。
