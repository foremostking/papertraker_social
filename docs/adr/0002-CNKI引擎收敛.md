# ADR-002：CNKI 接入收敛为 aiohttp 单一活动引擎

- 状态：已接受
- 日期：2026-08-05
- 关联：ADR-001、ADR-007（P1）

## 背景

`scholarpilot/src/scholarpilot/mcp/servers/cnki/` 下共存 3 个引擎：

| 引擎 | 文件 | 状态 |
|---|---|---|
| `CNKIAiohttpEngine` | `aiohttp_engine.py` | **推荐/默认**，`__init__.py` 文档自认"基于已验证方案重建" |
| `CNKIEngine`（httpx） | `server.py` | 文档自认"旧方案，可能被 CAPTCHA 拦截" |
| `CNKIPlaywrightEngine` | `playwright_engine.py` | 浏览器内 fetch，验证码兜底 |

此外，同一份 QueryJson / `Resource=JOURNAL` / `Classid=YSTT4HG0` / `ControlGroup+YE` 逻辑在归档的 `papertracker_social`、`papertracker_rich/literature_fetcher`、`papertraker_20260124` 中被重复实现。CNKI 接口一旦变化需同步多处。

实测证据：`aiohttp_engine` 用真实 Cookie 检索"地方政府债务"返回 731 篇（2026-08-05），为当前唯一可靠实现。

## 决策

**以 aiohttp 为 CNKI 的唯一活动引擎。**

1. 删除 `server.py` 中的 `CNKIEngine`（httpx）。其数据模型 `CNKIPaper` / `CNKISearchResult` 需先搬迁到 `aiohttp_engine.py` 或独立 `models.py`，再删除该类。
2. `playwright_engine.py` **保留文件但移除默认导出**，改为按需 `try: from .playwright_engine import ...`，仅作为验证码兜底的备选插件。
3. `cnki_cookie_cache.json` 从源码删除并加入 `.gitignore`——Cookie 属运行时凭据，不应检入版本库。

## 后果

- **正面**：CNKI 只保留一个维护点；删除冗余引擎；避免 Cookie 凭据泄漏到版本库。
- **负面/成本**：playwright 兜底能力仍在但不再是默认路径，若后续 CNKI 频繁验证码，需显式开启；`server.py` 删除需保证数据模型引用已迁移（依赖关系在 P1 执行时验证）。
- **风险控制**：删除前先跑一次真实检索（参考 `scripts/run_real_cnki_collect.py`）确认 aiohttp 通路稳定。

## 跨子系统原则

本 ADR 只处理 `scholarpilot/` 内部。归档子系统中的 CNKI 实现**不再维护**（ADR-001），未来若需能力从 `scholarpilot/` 扩展，绝不新增第 4、5 份拷贝。
